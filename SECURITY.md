# Security Policy

## Supported Versions

tomotv is actively developed on the default branch. Only the latest version
published there receives security updates. Older commits, forks, and
unreleased branches are not maintained and should not be relied on for
security fixes.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in tomotv, please
report it privately. **Do not open a public issue, pull request, or
discussion for security problems**, as that would disclose the issue before
a fix is available.

Instead, email the details to:

**contact@keiver.dev**

Please include as much of the following as you can:

- A description of the vulnerability and the impact you believe it has.
- Steps to reproduce (a proof of concept, affected URL, request, or code
  path is very helpful).
- The version, commit, or environment where you observed it.
- Any suggested remediation, if you have one.

### What to expect

- **Acknowledgement:** You will receive a reply confirming the report within
  **3 business days**.
- **Updates:** You can expect a status update at least once every **7 days**
  while the report is being investigated.
- **If accepted:** The issue will be triaged, a fix prioritized, and you will
  be notified when it is released. Credit will be given to you in the release
  notes unless you prefer to remain anonymous.
- **If declined:** You will receive an explanation of why the report was not
  considered a security issue, along with any relevant context.

Please act in good faith: give us reasonable time to address the issue before
any public disclosure, and avoid privacy violations, data destruction, or
service disruption while investigating.

Thank you for helping keep tomotv and its users safe.
